AI agent & API quickstart

Start with read-only data. Public market data needs no account and no key. Everything beyond that is documented at docs.bitnxs.com/api and docs.bitnxs.com/ai-agent.

1. Public market data

Send a JSON body with a type field to POST https://api.bitnxs.com/info.

curl -s -X POST https://api.bitnxs.com/info \
  -H 'content-type: application/json' \
  -d '{"type":"allMids"}'

curl -s -X POST https://api.bitnxs.com/info \
  -H 'content-type: application/json' \
  -d '{"type":"marketSummary","coin":"BTC"}'

Other queries used on this site: meta, feeSchedule and fundingHistory (with a coin field). When an agent reports a number, it should print the time it was read.

2. The in-app AI agent (experimental)

Per the AI agent docs, the app has an experimental chat panel where an LLM you connect (any OpenAI-compatible endpoint, using your own key stored in your browser) reads your live account state and proposes a long, short or wait view. The docs list what it can do (switch market, switch side, place limit orders, read the account) and what it cannot (change leverage or margin mode, place market orders, cancel or modify orders, set TP/SL triggers). Orders run against your live session on real funds.

3. Grok Bot template (open source)

The bitnxs-grokbot repository (MIT license) is a template for the Grok Bot platform: a read-only market-brief skill using public data, a getting-started conversation, and an optional trading skill that works through your own Bitnxs API key. scripts/snapshot.py is a read-only market snapshot using only the Python standard library. Treat any API key as a secret and never paste it into a public place.

Limits

An AI agent can misread data, use stale prices or act on a bad prompt. A model's long or short call is an opinion with no guaranteed edge. Bitnxs has no demo mode, so test with read-only queries first.
